# Web Development: Weeks 2–5

Open **Web Development → Year 1 → Week 2, 3, 4 or 5 → Day 1–7** in Study Hub.
All explanations, exercises, answer explanations, challenges and quizzes are stored in
the existing HTML and work offline. Each day has three teaching parts, day notes,
heading notes, manual completion and previous/next navigation.

| Week | Focus | Project |
| --- | --- | --- |
| 2 | URLs, clients/servers, DNS/HTTPS, static/dynamic delivery, DevTools | Local/hosted page journeys and evidence table |
| 3 | Elements, document structure, attributes, nesting and metadata | Two clean documents |
| 4 | Documentation, comments, source/DOM and troubleshooting | Repair a page with a debugging log |
| 5 | Headings, prose, emphasis, lists and semantic regions | Complete study article with in-page navigation |

Each Day 7 includes a retrieval/repair workshop and a twelve-question explained quiz.
Repeat parts across sessions as needed. These are foundation weeks; later roadmap
weeks continue links, media, forms, CSS, JavaScript and application development.

## Authoring and preservation

The week2-content through week5-content scripts contain original English teaching.
The teaching-tools script provides authoring helpers only.
Run the weeks2-5 script with arguments 2 3 4 5 to merge entries atomically
into WEBDEV_TEACH. Other weeks are preserved. Revising Week 1 preserves later weeks.

No new storage schema: existing lessonsDone, lessonQuizScores and headNotes
use stable webdev:W.D keys. Existing export/import and configured sync include them.
The shared renderer, roadmap, design and other course content are unchanged.
