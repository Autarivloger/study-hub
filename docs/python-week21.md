# Python Week 21: learning and further practice

The original 19 parts remain in their original order, with every original section and saved identity retained. A short English/Nepali walkthrough follows each first example, explicitly tracing inputs, construction, calls and state changes.

Each of the six days now ends with one further-study guided lab:

1. Dataclass generation, independent defaults, explicit list ownership and frozen validation.
2. Type hints versus runtime validation, missing values versus zero, and a small typed module.
3. The five SOLID principles applied to readers, reports and formatting.
4. Factory/strategy assembly and observer subscription changes during notification.
5. Stable enum serialization, parsing and validated state transitions.
6. Behaviour-preserving refactoring and successful/failed stock changes.

Total: 25 parts, 50 practice prompts, 37 questions across 25 quiz checkpoints, and 56 executable examples/solutions. Additional labs use new `21.lab.*` practice IDs and `course:21.lab.*` quiz IDs. They are marked as optional further-study parts so adding them cannot invalidate previously completed days. Learners should use them whenever they need more explanation or practice.

`scripts/python-week21-deepen.cjs` adds these enhancements once and refuses duplicate installation. `tests/python-week21-deepen.cjs` pins the previous version and checks that old parts/sections/IDs are retained and all other subjects, application logic and storage are untouched. The snippet and browser tests verify executable output, multi-question quizzes, mouse selection, navigation, saved data and responsive layouts.
